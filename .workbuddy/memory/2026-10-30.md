## 真机手势失效根因修复（b03258f，0.2.1 已上 K70）

- 根因：双通道去重让先到的 pointer 通道（pointerType=touch）占坑，touchmove 被去重忽略；Android WebView 的 pointer 序列在滚动容器接管时被 pointercancel 截杀——聊天页竖向可滚，右滑必中，手势死在 START 后无任何日志。
- 取证路径：MuMu（127.0.0.1:16576，root）部署调试版（TEMP-DEBUG 强制 debugOn）+ `input swipe` 注入 + logcat；发现 adb push 必须 MSYS_NO_PATHCONV=1（否则目标路径被 Git Bash 转成本地盘路径——曾误判 push 成功）。
- 模拟器迭代通道：插件部署在 /data/data/app.dsh.mobile/files/engine/android-plugins/mobile-layout/；EngineConfig 按 package.json version 与 npm latest 比较决定覆盖，部署副本版本提到 > npm（现伪装 0.5.13）即可免重装 APK 直改文件。npm 上 @xiaopb/dsh-mobile-layout 已有 0.5.12（比仓库新）。
- 修复：onPointerDown 对 pointerType=touch 直接 return（触摸全走 touch 通道），pointer 只服务鼠标/笔。模拟器验证：聊天页开合、最左缘 x=3 起手、慢速拖拽、插件面板页右滑全通过。
- K70：0.2.1（assets 同步 + gradle assembleRelease -Ppackage=noruntime + adb install -r）部署成功，input swipe 注入验证抽屉开合正常。TEMP-DEBUG 日志（7 处）待真机人工验收后移除。
- K70 壳只转发 console WARNING 到 logcat（模拟器转发 INFO），console.info 取证在 K70 上不可见。
