# dsh-mobile-layout

**DSH 手机竖屏自适应布局插件（0.5.6）**

DSH 的 Web 客户端目前没有移动端布局：窄屏时左侧栏只是被压缩成 56px 轨道，右侧栏在 768px 以下才自动全屏，整份前端 CSS 没有任何宽度媒体查询。本插件在不修改官方内核、不替换官方布局插件的前提下，把**手机竖屏**切换成适合触控的形态：

- 左侧栏改为抽屉（汉堡入口 / 左缘滑动打开 / 遮罩或左滑关闭），不再占用内容宽度；
- 输入框下方新增 56px 常驻条：新建 / 会话 / 文件 / 图片 / 插件 / 更多；加号面板贴屏幕最底部，以 4 列宫格（48px 圆角图标 + 标签）展开，常驻条与输入行随之上移，再点 ⊕ 旋转成 × 收起；面板与常驻条同一表面（全宽、同底色、无圆角阴影），仅用一条分隔线区分；
- 输入行紧贴常驻条上沿（空会话态同样贴底，不再悬浮在页面中间）；输入行内的官方 ⊕ 隐藏，只保留常驻条最右侧的 ⊕；
- 输入区与常驻条融合为同一条全宽底部面板：去掉官方输入卡的圆角、边框、阴影与左右留白，宽度与常驻条一致，面板之间只用一条 1px 分隔线（输入区顶端）区分；输入区顶端与上方会话正文之间的分界线加深为 1px `rgba(0,0,0,0.14)`（官方 0.5px 浅灰在窄屏缩放下几乎不可见），「对话输入区」与「信息页面」边界明确；
- 空态输入卡片收紧：输入框一行高度由官方 36px 压到 24px（2/3）并去掉顶部内边距，工具行上方留白压到 4px；多行输入仍按官方逻辑自增长，空态不再有大段空白；
- 权限模式留在输入行左侧，显示「图标 + 短文案」（完全访问 / 工作区 / 只读）；模型与思考等级留在右侧并显示短名（`V4.1 · H`），点击保持官方原始弹层，不再底部化；
- 会话统计（轮次/速度、Token 用量、上下文占用）从输入区挪到会话标题栏下方的常驻细条，正文从细条下方开始；详情弹层固定在该细条下方展开；右栏全屏时细条隐藏；
- 右上保留官方右栏开关；紧凑顶栏与 44px 触控目标，右栏全屏时补安全区、顶部工具放大到 44px，返回键优先关闭右栏；
- 右上角 `⋯` 打开官方菜单时保持右上角下拉列表：紧贴按钮下沿、右缘紧贴窗口（Android WebView 缩放导致 `right: 0` 内缩时按实测空档自校正），不再并入底部面板；菜单展开期间统计细条临时隐藏，避免重叠遮挡，关闭后恢复；菜单面不透明，且展开时把菜单到顶栏的祖先链抬成层叠上下文，越过官方 `_tabs`（对话/轨迹 切换条，透明但全宽），菜单内「下载 Session 日志」等首行可正常点击；
- 浮层互斥：抽屉、底部表、加号菜单不会叠加；遮罩 / 左滑 / Android 返回键都能关闭当前浮层；
- 按视口宽度、高度比例与方向自动判定「手机竖屏」，其他形态（横屏、平板、桌面）**保持官方默认布局**，像素级不变；
- 全量样式受 `data-dshm-mode="mobile"` 作用域保护，锚点失败或插件卸载即回退默认布局。

## 状态

0.5.6：形态判定、抽屉、底部常驻条、会话/插件底部表、文件/图片回流、贴底宫格面板（与常驻条同表面、分隔线区分、⊕ 二次点击收起）、输入区与常驻条融合（去圆角/边框/阴影、全宽同表面）、输入区与上方会话正文之间的 1px 分界线（0.5px 浅灰改为 `rgba(0,0,0,0.14)`）、输入行贴底与输入行内 ⊕ 隐藏、权限/模型恢复官方原始弹层、输入区短名 chip、右栏返回键与安全区、会话统计状态带（标题栏下方常驻细条、详情弹层下移、右栏全屏隐藏、顶栏菜单展开时临时隐藏）、右上角 `⋯` 下拉菜单（紧贴按钮、右缘自校正贴住窗口右缘、菜单面不透明、展开时抬升祖先层叠上下文越过官方 `_tabs` 使首行可点击）、空态输入框收紧到官方一行高度的 2/3 且多行仍自增长均已实现，并在 MuMu 模拟器（360×640dp 竖屏）与 Playwright 360×640 验证（含「下载 Session 日志」实机点击后生成 ZIP）；软键盘弹起保持手机布局。实施计划与验收矩阵见 [docs/mobile-layout-plan.md](docs/mobile-layout-plan.md)。

## 安装

```sh
dsh plugin --profile web add @xiaopb/dsh-mobile-layout
```

## 命名

选 `dsh-mobile-layout`：与已有的 `dsh-mobile-compose`（手机端输入体验）形成同一命名族，职责边界清晰——`compose` 管输入，`layout` 管外壳。
